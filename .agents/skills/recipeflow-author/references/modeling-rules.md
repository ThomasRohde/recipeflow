# Modeling rules

- Every ingredient must be consumed or explicitly marked optional, garnish or reserved in later milestones.
- Every intermediate must be produced before use.
- A setup action produces a prerequisite, not a material.
- A transformation consumes zero or more materials and produces one or more new materials.
- Mark one or more final outputs.
- Represent repetition as metadata, not cycles.
- Preserve ambiguity in notes until the ambiguity model lands in M2.
- Use evidence fields where supported; never fabricate source claims.
